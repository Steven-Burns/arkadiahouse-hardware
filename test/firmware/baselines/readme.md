# baselines

This folder contains minimal esphome configurations for the various borads used in the project.

These are useful for onboarding (get it? a board on board?!), bootstrapping, and resetting a board to a configuration where it can connect to the Home Assistant instance and subsequently be flashed to a particular role.

## resetting a board 

1. Build the board's esphoime confiration YAML file.
1. Flash the board with the built bin
